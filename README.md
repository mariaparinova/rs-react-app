# RS React App — Forms

A learning project built with **React + TypeScript** using [Vite](https://vite.dev/).  
Implemented as part of the [RS School – React course: forms](https://github.com/rolling-scopes-school/tasks/blob/master/react/modules/tasks/forms.md).

## Scripts

- npm run dev — run Vite dev server
- npm run build — build the project
- npm run preview — preview the production build
- npm run lint — run ESLint
- npm run format:fix — auto-format with Prettier
- npm run test — run tests with Vitest
- npm run coverage — run tests with a coverage report
- npm run prepare — install Husky hooks automatically
